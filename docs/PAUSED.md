| Metro 실행 시 `configs.toReversed is not a function` | 셸 기본 Node가 18. **이 프로젝트는 Node 20** (`.nvmrc`) |

## 중단하면서 해둔 것

- `scripts/tunnel.sh` 종료 (서버 + 터널). 노트북이 `caffeinate`로 안 자고 있었다
- 스케줄 작업 3개 비활성화 — 아침 리포트 / 경기 전 점검 / 주간 정리.
  켜두면 죽은 서버를 두고 매일 알림이 온다. 재개할 때 다시 켤 것
- 데이터는 `data/` 의 H2 파일에 그대로 있다. 지우지 말 것

### 재개 절차

```bash
# 1. 서버 + 터널
cd tagup-backend && ./scripts/tunnel.sh

# 2. 앱 (Node 20 필요)
cd tagup-frontend && npx expo start -c
```

자격증명은 레포 밖에 있다. 없으면 서버가 기동을 거부한다.

- `tagup-backend/.env` — `FIREBASE_PROJECT_ID`, `FIREBASE_CREDENTIALS_PATH`, `ADMIN_EMAILS`
- Firebase 서비스 계정 키 — `~/.config/tagup/firebase-service-account.json` (권한 600)
- `tagup-frontend/.env.local` — Firebase 설정과 API 주소. 터널 스크립트가 주소를 자동으로 고친다

### 알아둘 것

아침 리포트 스케줄 작업이 **승인 대기에 걸려 멈춘 적이 있다.** 재개 후 한 번 수동 실행해
권한을 승인해 두면 그다음부터는 혼자 돈다.
